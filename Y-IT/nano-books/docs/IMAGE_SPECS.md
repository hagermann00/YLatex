# Y-IT NANO-BOOK IMAGE SPECIFICATIONS

**Visual design specifications for 6×9" print format**

---

## IMAGE BUDGET: 6 IMAGES PER NANO-BOOK

### Rationale
- 6 images across 12-14 pages = ~2 pages per image average
- Allows text breathing room
- Each image must justify its space
- Constraint forces quality over quantity

---

## IMAGE INVENTORY

### 1. COVER (Exterior - doesn't count against interior budget)

**Specifications:**
- **Size:** 6×9" + bleed (typically 6.125" × 9.25")
- **Resolution:** 300 DPI minimum
- **Color mode:** CMYK (for print)
- **File format:** PDF or high-res PNG

**Design Requirements:**
- Bold typography-forward design
- Title clearly readable at thumbnail size (Amazon)
- Small satirical icon/illustration
- QR code to free AI evaluator (bottom corner)
- Universal Primer color palette (if using brand colors)
- High contrast for visibility

**Example Elements:**
- Large, bold title: "WHY YOUR DROPSHIP WILL FAIL"
- Small visual element: Sinking ship made of Amazon packages
- Subtitle: "92% fail within 12 months. Here's exactly why."
- QR code: "Test your idea FREE"

**Style Notes:**
- Professional but satirical
- Not "self-published" looking
- Think: Corporate report meets dark comedy
- Credibility > cuteness

### 2. TITLE PAGE HERO ILLUSTRATION (Page 1 - Interior)

**Specifications:**
- **Size:** 4.5" × 4" (½ page vertical space)
- **Resolution:** 300 DPI
- **Color mode:** CMYK
- **Style:** Clean linework, limited color (2-3 colors max)
- **File format:** Vector (AI/SVG) or high-res PNG

**Design Requirements:**
- **High contrast for print reproduction**
- Simple composition (no tiny details that won't print)
- Instant tone-setting (satirical but professional)
- Complements title (doesn't compete)

**Dropshipping Example:**
**Scene:** Split-frame composition
- **Left side:** Laptop screen showing Shopify dashboard with $0.00 sales
- **Right side:** Smartphone showing guru Instagram (yacht, cash, "Just shipped $50K today!")
- **Center:** Exhausted entrepreneur slumped between both devices
- **Visual metaphor:** The disconnect between promise and reality

**Universal Template:**
Each topic uses same split-frame concept:
- Left = Reality (the user's actual situation)
- Right = Promise (guru fantasy)
- Center = Victim (entrepreneur caught between)

**Placement:**
- Top ½ of page 1
- Bottom ½ = Title, subtitle, tagline, QR code to web version

**QR Code Integration:**
- Small QR code in corner: "See the full failure timeline (animated comic)"
- Links to web version with 6-panel comic strip

### 3-5. CASE STUDY ICONS (Pages 4-7 - 3 icons total)

**Specifications:**
- **Size:** 1.5" × 1.5" (¼ page)
- **Resolution:** 300 DPI
- **Color mode:** CMYK
- **Style:** Simplified icon style (sophisticated emoji-like)
- **File format:** Vector (AI/SVG) or high-res PNG

**Design Requirements:**
- **NOT full portraits** (too large for space)
- Archetypal representation (instant recognition)
- Consistent style across all 3
- High contrast (must print clearly at small size)
- Visual shorthand for character type

**Icon Style Guide:**

**Icon 1: Trust Fund Failure**
- Silhouette holding money bag with hole in bottom
- Dollar signs falling through
- Colors: Gold (money) + Red (loss)
- Visual shorthand: "Money can't save you"

**Icon 2: Spiritual/Wellness Type**
- Silhouette in meditation pose
- Thought bubble with dollar signs (manifestation)
- Calculator with X through it (math denial)
- Colors: Purple (spirituality) + Red (reality check)
- Visual shorthand: "Manifestation meets mathematics"

**Icon 3: Pyrrhic Victory**
- Silhouette holding trophy
- Body language exhausted/broken
- Background: Broken relationships, health symbols
- Colors: Gold (success) + Gray (destruction)
- Visual shorthand: "Won the battle, lost the war"

**Placement:**
- Top left of case study section (¼ page)
- Text wraps around right side
- Icon + case study = 1.25 pages total

**Web Version Upsell:**
- Print: Simplified icon
- Web: Full illustrated portrait + expanded story
- QR code near icon: "See full portrait + backstory"

### 6. COST BREAKDOWN VISUALIZATION (Page 8)

**Specifications:**
- **Type:** ASCII-style table (text-based, NOT image)
- **Size:** ½ page
- **Font:** Monospace (Courier or similar)
- **Color:** Black text, possibly one accent color for negative number

**Design Requirements:**
- Simple, readable at print size
- Uses typography, not complex infographics
- Looks "spreadsheet authentic" (reinforces credibility)
- Shocking bottom line (emphasize the loss)

**Template:**

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
THE MATH NOBODY TELLS YOU
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Product Sale Price:           $24.99
                             ───────
COSTS:
  Supplier (AliExpress)       -$6.50
  Shipping (ePacket)          -$4.20
  Platform fees (Shopify)     -$2.50
  Payment processing (3%)     -$0.75
  Facebook ads (per sale)    -$25.00
  Packaging/inserts           -$1.50
  Returns (15% rate)          -$3.75
                             ───────
TOTAL COSTS:                 -$44.20

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**Typography Emphasis:**
- Bold negative profit number
- Skull emoji or warning symbol
- Final guru quote in italics (satirical punch)

**Alternative Visual Treatment:**
Could be designed as simple bar chart showing:
- Revenue bar (small)
- Cost bars stacked (massive)
- Difference = negative space (loss)

But ASCII table is:
- Faster to produce
- Cheaper (no designer needed)
- More credible (looks like real spreadsheet)
- Easier to update across topics

**Web Version Upsell:**
- Print: Static ASCII table
- Web: Interactive calculator ("Enter your numbers, see YOUR loss")
- QR code below table: "Calculate your actual numbers"

### 7. DECISION FRAMEWORK FLOWCHART (Page 10)

**Specifications:**
- **Type:** ASCII-style flowchart (text-based with arrows)
- **Size:** ½ page
- **Font:** Monospace or clean sans-serif
- **Color:** Black text + possibly red for "Don't do this" paths

**Design Requirements:**
- Maximum 3-4 decision points
- Clear Yes/No paths
- Most paths lead to "Don't do this" (reflects reality)
- One path to "Maybe try it, but..." (rare scenario)

**Template:**

```
┌─────────────────────────────────────────────┐
│   SHOULD YOU ACTUALLY DO THIS?              │
└─────────────────────────────────────────────┘

Do you have $50K+ you can afford to lose?
    │
    ├─► NO  ──────────────────────────────┐
    │                                      │
    └─► YES                                │
        │                                  │
        Can you work 60+ hours/week?       │
        │                                  │
        ├─► NO  ──────────────────────────┤
        │                                  │
        └─► YES                            │
            │                              │
            Do you have 12+ months runway? │
            │                              │
            ├─► NO  ──────────────────────┤
            │                              │
            └─► YES                        │
                │                          │
                ▼                          │
        Maybe try it, BUT:                 │
        • Read alternatives first          │
        • Expect to lose money            │
        • Track time obsessively          │
                                          │
                                          ▼
                    ┌──────────────────────────────┐
                    │  DON'T DO THIS               │
                    │                              │
                    │  See page 11 for what to     │
                    │  do instead (better ROI)     │
                    └──────────────────────────────┘
```

**Typography Emphasis:**
- Red text or box for "DON'T DO THIS"
- Different font weight for questions vs outcomes
- Clear visual hierarchy (questions → paths → verdict)

**Alternative Visual Treatment:**
Could be designed as illustrated flowchart with icons, but ASCII version is:
- Faster to produce
- More serious/credible (matches business decision framework)
- Easier to update across topics
- Reinforces "no nonsense" Y-IT brand

**Web Version Upsell:**
- Print: Static flowchart
- Web: Interactive quiz with personalized recommendations
- QR code below chart: "Take the full assessment (15 questions)"

## VISUAL STYLE GUIDE

### Color Palette
- **Primary:** Black & white (maximum contrast)
- **Accent 1:** Red (warnings, losses, "don't do this")
- **Accent 2:** Topic-specific color (e.g., blue for dropshipping, green for affiliate)
- **Limit:** 3 colors maximum per image

### Typography
- **Headings:** Bold, sans-serif, high contrast
- **Body:** Readable serif or sans-serif, 11pt minimum
- **ASCII elements:** Monospace (Courier, Consolas)
- **Emphasis:** Bold or italic, NOT color alone

### Illustration Style
- **Clean linework** (no sketchy/messy lines)
- **Limited detail** (must print clearly at 6×9" format)
- **High contrast** (avoid gradients, subtle shading)
- **Satirical but professional** (dark comedy, not cartoon)

### Avoid
- ❌ Gradients (don't print well)
- ❌ Tiny text in images (unreadable at print size)
- ❌ Stock photo clichés (laptop on beach)
- ❌ Cutesy illustrations (undermines credibility)
- ❌ Too many colors (looks amateurish)

## PRODUCTION WORKFLOW

### For Each Nano-Book Topic

**Week 1: Design Phase**
1. Commission cover design
2. Sketch title page hero illustration
3. Design 3 case study icon concepts
4. Create ASCII table template
5. Create ASCII flowchart template

**Week 2: Production**
6. Finalize cover (print-ready)
7. Finalize title page illustration (print-ready)
8. Finalize 3 case study icons (print-ready)
9. Format ASCII tables with actual data
10. Format ASCII flowchart with actual logic

**Week 3: Web Extension**
11. Animate 6-panel comic strip
12. Illustrate 7 full character portraits
13. Design interactive charts/calculators
14. Generate QR codes linking print to web

**Deliverables:**
- 2 exterior images (cover, back cover)
- 6 interior images (1 hero, 3 icons, 2 text-based visualizations)
- Web-exclusive: Comic strip + 7 portraits + interactive charts

## BUDGET CONSIDERATIONS

### Print Images (per nano-book)
- Cover design: $200-400 (one-time)
- Title page hero: $150-250
- 3 case study icons: $50-100 each = $150-300
- ASCII tables: $0 (text-based, DIY)
- ASCII flowchart: $0 (text-based, DIY)

**Total print images:** $500-950 per nano-book

### Web Images (per nano-book)
- 6-panel comic strip: $300-600 (or animated: $500-1000)
- 7 character portraits: $100-200 each = $700-1400
- Interactive chart designs: $200-400

**Total web images:** $1,200-2,400 per nano-book

### Total Visual Budget Per Nano-Book
**$1,700-3,350** (can scale down by doing ASCII tables, simple icons, etc.)

### Cost Reduction Strategies
1. **Use ASCII for all data viz** (tables, flowcharts) → Save $0
2. **Simple icon style** (flat design, minimal detail) → $50/icon vs $150/icon
3. **Reuse illustrator** across all 7 topics → Volume discount
4. **Outsource to Fiverr/Upwork** → Lower rates but manage quality carefully

## QUALITY CHECKLIST

Before finalizing any image:

- [ ] **300 DPI minimum** (print quality)
- [ ] **CMYK color mode** (for printing)
- [ ] **High contrast** (no subtle grays that won't print)
- [ ] **Readable at actual size** (test print at 6×9")
- [ ] **On-brand** (satirical but professional, not cartoonish)
- [ ] **QR codes work** (test scan before printing)
- [ ] **File format correct** (PDF for print, PNG/SVG for web)
- [ ] **Bleed included** (if full-bleed design)
- [ ] **Text not too small** (11pt minimum for body text)
- [ ] **Aligns with Universal Primer guidelines** (if using brand colors)

## CONCLUSION

**6 images. 12-14 pages. Maximum impact.**

Every image must justify its existence. The constraint forces quality over quantity, aligning perfectly with Y-IT's "no fluff" philosophy.

**Print = Gateway.** Simple, high-impact visuals that create hunger for web version.

**Web = Destination.** Rich, interactive visuals that justify premium pricing.

**The visual strategy mirrors the content strategy: Brutal efficiency in print, expansive depth in digital.**
