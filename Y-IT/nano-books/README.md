# Y-IT NANO-BOOKS PROJECT

**A brutally honest, multi-format reality check for hyped business opportunities.**

---

## PROJECT OVERVIEW

The Y-IT Nano-Books series transforms comprehensive business analysis into compact, multi-format content ecosystems designed to prevent financial disasters before they happen.

### The Y-IT Philosophy

- **Satirical but empathetic:** "Beautiful, stubborn fool" tone
- **Data-driven:** Statistical honesty over motivational fluff
- **Actionable:** Clear decision frameworks, not vague inspiration
- **Multi-format:** Print gateway → Web deep-dive → Podcast extended universe

## FORMAT SPECIFICATIONS

### Print Version
- **Format:** 6×9" trade paperback
- **Page count:** 12-14 pages
- **Word count:** ~4,000 words
- **Images:** 6 total (title hero, 3 case study icons, cost table, decision tree)
- **Price:** $2.99 (Amazon KDP)

### Web Version
- **Format:** Responsive web app
- **Content:** Print content + 7 full case studies + interactive tools
- **Features:** Calculators, expandable sections, progress tracking, annotations
- **Price:** $7.99 one-time OR $4.99/month subscription

### Podcast Version
- **Format:** 20-25 minute episodes
- **Content:** Extended analysis beyond written content
- **Distribution:** Spotify, Apple Podcasts, YouTube
- **Monetization:** Free (marketing) or Patreon premium

### AI Evaluator
- **Format:** 1-2 page PDF delivered via email
- **Function:** Brutal product/idea analysis with book citations
- **Price:** Free (lead magnet)
- **Conversion:** Free roast → $2.99 print → $7.99 web → $99/year subscription

## BRAND VOICE GUIDELINES

### Tone
- **Satirical but empathetic:** Mock the gurus, not the victims
- **Data-driven:** Every claim backed by statistics
- **Professional irony:** Corporate dystopia meets dark comedy
- **Actionable cynicism:** "Here's why it fails AND what to do instead"

### What Y-IT Is NOT
- Motivational fluff
- "Just work harder" advice
- Guru worship
- Vague platitudes
- False hope

### What Y-IT IS
- Statistical reality checks
- Pattern recognition (why most attempts fail)
- Decision frameworks (should YOU attempt this?)
- Empathetic honesty ("I see you, beautiful stubborn fool")
- Alternatives (what to do instead)

## GETTING STARTED

### For Writers
1. Review `/docs/STRATEGIC_ANALYSIS.md` for complete framework
2. Use print manuscript template in `/print/[topic]/manuscript/`
3. Follow word count allocations (4,000 words total)
4. Include standardized section names (for AI Evaluator citations)

### For Designers
1. Review `/docs/IMAGE_SPECS.md` for visual requirements
2. Create 6 images per nano-book (title hero, 3 icons, 2 charts)
3. Maintain Y-IT brand style (satirical, clean, high-contrast)
4. Design for 6×9" print reproduction

### For Developers
1. Build web platform with expandable sections
2. Create interactive calculators (cost breakdowns, ROI tools)
3. Implement progress tracking and annotations
4. Integrate QR code analytics

### For Podcast Producers
1. Script 20-25 minute episodes per topic
2. Book interview guests (real failed entrepreneurs)
3. Record "Guru Roast" segments with actual guru pitches
4. Include "Calculator Corner" walk-throughs
